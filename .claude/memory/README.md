# Shared project memory (git-tracked)

Этот проект используется с разных аккаунтов Windows (Mi и Катя), а встроенная
auto-memory система Claude Code хранится per-account в домашней папке
(`~/.claude/projects/<hash>/memory/`) и поэтому НЕ расшаривается между аккаунтами.

Поэтому для фактов, которые должны быть видны из любого аккаунта, используем
эту папку вместо встроенной памяти — она лежит в репозитории и расшаривается
через `git pull`/`git push`, как обычный код.

## Как использовать

Формат файлов такой же, как у встроенной памяти Claude Code:

```markdown
---
name: kebab-case-slug
description: одна строка — когда это релевантно
metadata:
  type: user | feedback | project | reference
---

Содержание факта. Для feedback/project — строка **Why:** (почему) и
**How to apply:** (когда применять).
```

Каждый файл регистрируется одной строкой в `MEMORY.md` (индекс, без своего контента):

```
- [Заголовок](file.md) — короткий хук
```

## Правила

- Не дублировать то, что уже видно из кода/git-истории/CLAUDE.md.
- Не создавать новые skills/rules/memory, если подходящие уже есть в другом
  проекте этого аккаунта (Maxmobiles-Cursor, Technoprice-cursor) — сначала
  сверяться с ними.
- Коммитить изменения памяти так же, как обычный код — отдельным осмысленным
  коммитом или вместе с относящимся изменением.
